# Privacy Policy for Sharefi

**Effective Date:** October 1, 2026

Because **Sharefi** is a fully offline, open-source, local-network file sharing application, **your privacy is built directly into the architecture**. This Privacy Policy explains exactly how the application handles data.

---

### 1. No Data Collection (Zero Telemetry)
Sharefi does not collect, log, or store any personal data, analytics, or usage statistics. 
* There are **no external tracking scripts**, no background telemetry, and no cookies. 
* Everything you do inside the application remains strictly on your local device.

### 2. Local-Only Processing (No Cloud)
All file transfers and device discoveries happen **100% offline** within your private local network (LAN / Wi-Fi / Ethernet). 
* Your files, folder structures, and metadata **never touch the cloud** or any third-party external servers.
* Communication between your own devices is handled via a lightweight local HTTPS server, ensuring local traffic is securely encrypted from node to node.

### 3. No User Accounts
You are not required to create an account, share an email address, or provide any personal details to use Sharefi. The application features **zero setup barriers** and works the instant it is launched.

### 4. Code Transparency
As an **open-source project**, the entire codebase is fully transparent and available for auditing. Anyone can inspect how data is processed, ensuring absolute confirmation that no backdoors or hidden trackers exist.

### 5. Third-Party Services
Sharefi does not integrate with any third-party advertising networks, analytics platforms, or external cloud storage providers.
